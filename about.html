关于 Kaede Rei

我是 Kaede Rei，华南农业大学本科生、机器人开发者，也是 AgroTech-SCAU 的主要负责人之一

开发方向 ​

  • 机械臂方向关注模型、驱动、控制与标定在可调试工具中的实现
  • 嵌入式方向参与通信、设备抽象与控制开发，整理可跨项目复用的模块
  • 系统集成方向通过接口、配置与状态管理串起设备、软件模块与任务流程

我也在探索双臂遥操作、示教数据与模仿学习的训练和部署

相关项目 ​

  • SerialArm-Core

    覆盖模型与硬件配置、控制、示教和标定，提供 C++ 和 Python 接口，可选接入 ROS 2 与 MoveIt 2

    个人仓库 · 已有 Linux 发行版 · 持续开发

  • AT Robot Studio

    在独立的机器人工程中接入子系统、配置可复用任务，用层级状态机与行为树编排工作流，在运行台查看状态、反馈与诊断

    组织项目 · 已发布源码版本 · 持续开发

  • Embedded Control SDK

    SDK 提供通用通信、设备与控制模块，各项目负责业务流程、装配关系和平台配置

    组织项目 · 持续维护 · 按模块标注成熟度

    面向眼在手上场景的可视化手眼标定工作台，将相机与机器人数据接入统一流程，串联采样、诊断求解和独立验证

    组织项目 · 公开工具 · 眼在手上流程

  • Dual-DM-Arm-LeRobot

    双臂遥操作、示教数据处理与模仿学习策略部署实验

    个人仓库 · 探索与实验

    早期机器人系统的软件基线，相关模块与经验延续到后续工程

    组织项目 · 历史软件基线 · 仓库开放
