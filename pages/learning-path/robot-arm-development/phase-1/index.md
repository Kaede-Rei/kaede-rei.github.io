本章面向机械臂系统与运动控制开发者，沿机构与承载、驱动与反馈、几何基准、质量与动力学展开，说明机械设计如何决定模型的可信度、运动能力和控制效果

学习本章后，应能读懂与控制有关的机械图纸和参数，检查实物与模型是否对应，识别需要机械调整、重新测量或软件补偿的问题，并与机械人员明确可实现的运行条件；材料、加工和结构计算学习到能够理解约束、核对依据和提出具体问题的程度

文中的数值算例只用于说明关系；具体机械臂的性能要求、参数和限值，应由作业任务、所选部件资料及实物测量确定
