## 知识结构

| 知识模块 | 对应章节 | 主要作用 |
| --- | --- | --- |
| 系统基础 | 第二部分第 1—3 节 | 组织程序、接入设备、维持实时运行与故障处置 |
| 模型与信息基础 | 第二部分第 4—6 节 | 提供运动学、动力学、标定参数、状态估计与环境信息 |
| 控制 | 第二部分第 7—8 节 | 根据目标和反馈形成关节或末端控制作用 |
| 运动生成与规划 | 第二部分第 9—10 节 | 生成连续参考并求解环境约束下的运动 |
| 技能与任务 | 第二部分第 11 节 | 组合操作能力、选择动作并管理任务执行 |
| 学习方法 | 第二部分第 12—13 节 | 组织示范与数据，训练并接入学习型策略 |
| 验证与实施 | 第二部分第 14—15 节 | 建立仿真、验证算法、部署实机和维护系统 |

动作能力按关节与任务空间控制、轨迹生成、路径规划、操作技能与任务逐步建立，模型和感知为各模块提供共同输入

基础关节控制只依赖必要的关节反馈与模型，视觉可并行学习，仿真与测试随各模块开展，不必等全部算法完成后再开始
