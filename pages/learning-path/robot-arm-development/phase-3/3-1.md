## 3.1.1. 设备边界与连接

确定外设的独立功能、本地控制和系统调用关系，明确机械定位、供电、通信及气液接口；先说明设备接受什么请求、返回什么数据或状态，以及动作依赖哪些安装与供能条件，再决定与机械臂的接入方式

外设应按实际安装和运动关系进入整机模型，分别处理坐标、质量属性、运动部件和碰撞包络；不能将所有外设都作为腕部负载，也不能因为设备拥有独立控制器而忽略其机械作用

| 安装与运动关系 | 模型中的归属 | 对后续开发的影响 |
| --- | --- | --- |
| 随连杆运动的相机、工具和转接板 | 质量、质心和惯量归入实际随动连杆，并建立安装坐标与碰撞几何 | 影响重力与动态补偿、空间变换和运动包络 |
| 固定在工位上的相机、夹具和工作台 | 建立工位坐标与环境碰撞关系，不计入机械臂的运动负载 | 影响目标定位、基座配准和环境避碰 |
| 改变基座或工件位置的辅助轴 | 根据实际连接建立运动关系，使用轴状态更新相应坐标 | 影响运动学、目标状态、规划和同步执行 |
| 工具中的活动部件 | 根据相对运动表达状态与几何，必要时更新质量分布或采用说明过的近似 | 夹爪开合、伸缩等状态可能改变碰撞包络及作业位置 |

例如相机固定在前臂上时，其质量应归入前臂的实际随动结构；眼在手上的名称并不意味着它一定安装在末端法兰，具体归属沿用第一部分第 4.1 节的原则

连接检查应落实到引脚定义、电压、电平、输入输出类型、驱动能力和接线关系，区分供电端与信号端；电源还要满足实际持续电流、启动与动作峰值，以及连接器和线缆条件，不能仅凭接口名称或标称电压判断兼容；厂商工具接口会分别规定持续电流、短时峰值及启动负载条件，使用时按具体设备核对[[tool-electrical]](https://www.universal-robots.com/manuals/EN/HTML/SW10_7/Content/prod-usr-man/complianceUR20/H_g5_sections/tool_i_o_inst_spec.htm)

区分设备独立工作、接受上层动作请求和参与同步控制三种方式；独立设备仍需向系统提供必要状态，动作请求需要完成与异常反馈，参与同步控制则还需确定采样、执行时刻与通信条件；同一种物理连接并不自动满足这三种用途

## 3.1.2. 动作与状态接口

定义动作参数、单位、范围及生效条件，区分受理、就绪、执行、完成、失败与取消；“受理”表示设备接受了相应请求，“完成”应对应设备能够确认的动作结果，当前反馈不足以确认时应明确返回未确认状态及已有信息

规定命令与反馈的关联、重复请求处理和有效期限；查询状态、设置目标和触发一次性动作具有不同含义，重复报文不能无说明地触发第二次剪切或释放，旧命令在重连后是否仍有效也应有明确规则

说明反馈来自传感器、局部控制判断还是过程推断，并给出相应采样时刻与有效状态；设备能够报告的结果应有实际反馈依据，不能把命令已写入、动作计时结束和作业已经成功混为一项

实现本地异常处置与状态上报，说明设备在上层失联、取消或复位时实际如何动作，哪些状态需要重新确认；整机控制权、停止与恢复遵循第二部分第 3 节，任务恢复由第二部分第 11 节组织，本地处理与上层请求应保持一致
