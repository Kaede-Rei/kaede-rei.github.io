4.3. 物联网入门

整理面向 STM32 与 ESP 系列模块的物联网入门路线，串起传感器、通信、MQTT 和云端物模型

可阅读

物联网 (IoT) 入门学习路径：从零基础到实战开发 ​

核心路线图：基础认知 → 硬件基础 → 软件编程 → 通信协议 → 嵌入式开发 → 云平台接入 → 项目实战 → 进阶提升

1.熟悉各类传感器的使用以及需要接入的设备的通信协议；

2.理清“云端-物模型”以及“物模型-单片机”之间的连接与通信本质并熟练使用通信；

3.学习基本的通信代码调试的技巧，能够知道哪里的代码连接上时出错的，比如串口通信；

4.基本使用 ESP32 或者 ESP8266 等网络模块的各项外设以及通信原理；

5.能够看懂云端操作的文档，比如中国移动的 onenet 平台，能够自己操作并创建新的物模型之类的；

6.掌握基础的 JSON 语言编写，能够使用 MQTTFX 等模拟器连接云端和物模型平台；

学习路径推荐：1.32 最小系统板的物联网实验（建议去试试）里面挺多代码调试的技巧（里面有比较基础的软件）
