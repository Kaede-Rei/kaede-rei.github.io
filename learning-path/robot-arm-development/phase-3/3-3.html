3.3. 末端工具

梳理末端工具的作业原理、机电与流体接口、本地固件和局部控制，并与机械臂模型联动

末端工具承担夹持、吸附或加工等局部作用，需要向整机提供可调用的动作和有物理依据的反馈；机械臂负责怎样接近、运动和恢复，工具负责说明自身正在执行什么、已经确认什么，以及当前还能完成哪些动作

3.3.1. 作业原理与机械设计 ​

按工件尺寸、材料、表面和允许损伤选择夹持、吸附、剪切、推拨或插装原理；同一种工具需要在实际对象上检查适用范围，例如软质表面可能因夹紧变形，粗糙或透气表面会改变吸附条件；这些差异会影响接触位置、动作参数和作业结果判据

确定开度、行程、力、速度、节拍和作业反力，设计传动、导向、柔顺及接触结构；工具输出应与作业需要对应，夹持还需考虑搬运时的姿态、加速度与偏心载荷；局部柔顺可以容纳一定位置偏差，也会改变受力后的实际工具位置，应明确哪些变形属于允许工作状态

校核法兰、定位、快换、防松、质量惯性与活动包络；包络应覆盖开合、伸缩和持物后的状态，不能只使用工具收拢时的外形；为易损件更换、清洁和检修保留空间，并确认这些操作是否改变安装基准、接触位置或原有标定

3.3.2. 电气与流体系统 ​

根据作业原理配置电机、驱动、控制器及供电，或阀、气缸、真空装置、管路与必要储能；按动作需求校核压力、流量、响应与泄漏，检查工具动作和保持阶段的实际条件；气源标称压力不能代替工具端动态压力，管路和阀的配置也会影响建立吸附、松开和复位的时间

按需要布置位置、力、压力、真空度或工件检测，说明安装位置与检测对象；例如供气压力正常只能证明相应测点的供气条件，不能直接代表工件处已经形成有效夹持；选取能够支持当前任务判断的反馈，不要求所有工具具有相同的传感配置

根据工具与任务确定断电、失压、堵转和过载时的保持或释放行为，说明该行为依靠机械锁止、弹性机构、持续驱动还是压力维持；依赖储能或封闭气路时，还需检查泄漏、载荷及可维持时间；软件设置“保持”并不会增加断能后的物理能力，某种结构能够防止立即脱落，也不自动证明此时仍具备正常作业的刚度和精度

将上述能力提供给整机停止流程；任务取消、通信中断和供能消失可能需要不同动作，取消当前操作不等于释放工件；是否继续保持、受控释放或等待人工处置，应依据实际状态与任务条件确定，并与第二部分第 3 节的停止和恢复要求相容

3.3.3. 固件与局部控制 ​

建立初始化、回零、就绪、执行和故障状态，实现位置、速度、力或压力的本地控制；明确各状态所需的反馈、允许接收的动作和退出条件，使工具能够脱离机械臂任务程序独立测试；测试时对照输入、实际动作和反馈，确认状态切换对应实物变化

为到位、夹紧、吸附、剪切完成以及堵转、滑落和泄漏建立可实现的判据，注明所用反馈及适用工况；仅有电机位置和电流时，某些情况下可能无法区分接触工件、碰到机械止挡与异常卡滞，应保留“未确认”或相应原始状态，而不是把无法观察的结果统一判为成功

一次动作结束与后续持续状态分别反馈；例如吸附建立后，搬运过程仍需按可用反馈更新吸附状态，并注明更新时间和有效性；工具提供本地能够确认的事实，第二部分第 6 节与第 11 节结合运动、感知和任务条件判断持物与作业结果

处理超时、取消、复位和重复请求，明确退出动作是否完成、工具是否仍在施力，以及重新就绪所需条件；超时不代表物理动作没有发生，重复请求也不应无条件重新触发一次剪切或释放；复位前后核对实际位置和持物情况，避免内部状态清空后继续使用与实物不符的动作前提

3.3.4. 工具模型与机械臂协同 ​

定义 TCP、作业方向、安装变换、质量惯性和碰撞体，TCP 求解使用第二部分第 4.5 节的方法，设备端保证安装与测量条件；说明这些参数对应的工具、装配方式和活动状态，例如伸缩机构改变作业点时，应使用与当前伸出量相符的几何关系

快换过程应区分工具接近或在位、机械锁紧以及当前工具与参数匹配；按设备实际具备的反馈或确认方法判断换装是否完成，再允许使用相应工具作业；接近信号与锁紧信号具有不同含义，例如部分快换的 Ready-to-Lock 只表示两侧已进入可锁紧距离[tool-lock]；手工换装可以采用明确的人工确认和必要测量，不必为此统一增加自动识别硬件

快换和持物后更新工具参数、负载与附着关系，不能仅切换工具名称而保留旧质量或碰撞配置；确认当前安装与参数对应，同时检查 TCP、安装变换和有关限制是否仍适用；抓取、释放或脱落引起的变化，应分别反映到动力学载荷与场景附着关系，不能只改其中一项

将运动到位、接触建立和工具动作组织为明确依赖，说明工具动作何时可以开始、哪些条件需要持续满足以及失败时提供何种反馈；整机作业成功与恢复由第二部分第 11 节组织，工具局部状态应成为其判断依据，而不是代替整机任务结果
