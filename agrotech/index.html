我在 ATIL 的工作

AgroTech Innovation Lab · AgroTech-SCAU

我是 AgroTech-SCAU 的主要负责人之一，参与项目组织与开发，主要关注机械臂控制、嵌入式软件和系统集成，也为后续项目整理公共模块和接口文档

相关工程 ​

  • AT Robot Studio

    在独立的机器人工程中接入子系统、配置可复用任务，用层级状态机与行为树编排工作流，在运行台查看状态、反馈与诊断

    组织项目 · 已发布源码版本 · 持续开发

    从源码安装，机器人接口、启动配置与业务流程由外部机器人工程提供

    阅读使用指南
  • Embedded Control SDK

    SDK 提供通用通信、设备与控制模块，各项目负责业务流程、装配关系和平台配置

    组织项目 · 持续维护 · 按模块标注成熟度

    Stable 对应模块文档中已确认的使用路径

    查看模块状态
